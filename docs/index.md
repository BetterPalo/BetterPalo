BetterPalo is a community-run guide to the public services of the Municipality of
Palo, Leyte. These pages cover how the project is built, who runs it, and why it
makes the decisions it does.

Start with the [architecture](architecture.md) page for how the site is built, or
the [charter](charter.md) for the scope and roles. The [decisions](decisions/0005-positioning-and-phased-roadmap.md)
record each durable choice with its reasoning.

These pages are also published at
[betterpalo-betterpalo.docs7.io](https://betterpalo-betterpalo.docs7.io). The
site is built from this folder, so edit the Markdown here, not the site.

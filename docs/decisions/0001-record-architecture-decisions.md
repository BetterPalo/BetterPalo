# 0001: Record architecture decisions

- Status: Accepted
- Date: 2026-11-03

## Context

Decisions about the stack, hosting, licensing, and data policy are easy to lose
in chat and pull request comments.

## Decision

Record durable decisions as numbered Markdown files in `docs/decisions/`.

## Consequences

Each decision has a stable link and a visible history. Contributors spend a
little time writing the record, and reviewers can reject a change that lacks
one.

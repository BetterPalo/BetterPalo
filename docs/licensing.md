## License map

| Path or artifact | License | Notes |
| --- | --- | --- |
| Source code, scripts, build configuration, GitHub workflows | MIT | See [`LICENSE`](../LICENSE). |

## Mixed files

A JSON or YAML file can contain both structured facts and original prose. The
facts, field names, and selection/arrangement are CC0. Original prose inside the
same file is CC BY-SA 4.0.

## Government works

Under Republic Act No. 8293 (RA 8293), Section 176, no copyright subsists in a
work of the Government of the Philippines, but prior approval of the agency that
created the work is necessary for exploitation for profit. BetterPalo does not
claim ownership of government-authored material. The project licenses only its
own selection, arrangement, normalization, and original write-ups. The source and
terms of every dataset are recorded in `data-sources.md`.

## Third-party material

Photos, logos, screenshots, quoted passages, and datasets owned by someone other
than the project or the government are excluded from all three licenses. Each
item must be recorded in `data-sources.md` with its source, owner, terms, and
permission status. If the terms are unknown, the item is not merged.

## Contributions

Contributions are inbound = outbound:

- code contributions are MIT;
- content and translation contributions are CC BY-SA 4.0;
- data contributions are CC0.

By submitting a contribution, you confirm that you have the right to license it
on these terms and that you have cited your sources. No contributor license
agreement is required.

## Questions

This is a project decision, not legal advice. Open an issue if a source's terms
are unclear.
